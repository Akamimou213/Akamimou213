# Storyboard variants (gate G4, when the direction is open)

After the assets and the reference scan, propose **three** genuinely different films for the same brief. Not three
palettes of one idea. For each one:

- **Name + logline:** one sentence, plus the turn or joke.
- **Grammar:** which reference moves it borrows (cuts vs one continuous shape, type pairing, accent element, camera).
- **Beat sheet:** 5–8 rows on the BPM grid (time · picture · words on screen · real asset used).
- **Hero moment:** the single frame people will screenshot.
- **Real assets it needs:** and whether we already captured them.
- **Risk:** what could look generic or break at phone size; production cost (light / medium / heavy).

Proven archetypes to start from (pick three that fit the product):
1. **Reference remake:** the reference's pacing and transitions, the client's real UI and copy (Walaw variant A:
   hook → product does X → books → grid → stamp → manifesto → lockup, hard cuts on two downbeats).
2. **One-shape morph:** a single element morphs logo → button → field → answer → loader → pin → map → list → tabs →
   board → search → logo, with a cursor driving real interactions; seamless loop (Walaw morph film).
3. **Kinetic type + real UI cards:** problem in ≤5 huge words, UI assembles piece by piece, three features as cursor
   moments, one verified number, logo + CTA (Walaw 20 s promo).
4. **Data/geography:** the product's real footprint on a dot-matrix map (only with verified per-item data).

End with a recommendation and why. Once the user picks, render **one still per scene** for that variant as a
contact sheet before animating anything.
