# Style guide — what we took from the reference

Reference: `Video-96789_1.mp4` (296 s, 720×1280, 24 fps). `refscan.sh`: 109 hard cuts, so the average shot is **2.7 s**;
tempo ~122 BPM; VO-led. Its content (product, claims, characters) isn't used.

| Reference grammar | Ours |
|---|---|
| Cobalt #1242BA family + terracotta/salmon accents + cream/white paper, navy darks | same palette tokens (`timeline.json` palette) |
| Gouache texture: dry-brush streaks, mottled fills, rough edges, paper grain | procedural seeded textures per colour, rough-edged panels, static grain overlay |
| Alternates full-bleed cobalt shots with illustrations framed on white paper | hook, phone, flow, end card full-bleed cobalt; the rest framed or objects on paper |
| One action per shot (a tower rises, a fish is netted, paint pours) | every shot has one verb: stamp, write, rise, wash, tap, drop, flow |
| Object-led shots: plate + cutlery, empty shelf grid, triptych of faces, split panels | calendar, clipboard, triptych (questions → answers), 2×2 grid, story vs summary |
| Serif lines (Garamond-like), sentence case, centred, lower-middle, white with a soft shadow; dark on paper | EB Garamond 400 at 66 px/1080, shadowed white on cobalt, navy on paper |
| Hard cuts on VO phrases; no transitions | all 12 cuts are hard cuts on word starts |
| Callbacks: the same mirror and woman return changed | the silhouette (knot → calm), the triptych (questions → answers), the calendar (marks → logs) |

What we push further: a single recurring character (the gut line), and a shorter story (30 s, 12 shots, ~2.5 s each).
